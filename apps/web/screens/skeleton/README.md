Walking skeleton screen (issue #32). Imports a bundled sample chat, shows the proposed terms with status symbol and word and links to their source messages, lets the user confirm terms one by one, then shows the recap with its echo code and the receipt. Demo mode only (`VERIDOC_DEMO_MODE=1`); a banner says the data is synthetic and the receipt is not for evidence. Tokens only, no CDN, chat text is shown with `textContent` and never as markup. `logic.js` holds the testable functions (`apps/web/tests/skeleton-logic.test.mjs`, run with `npm test` in `apps/web`); `skeleton.js` is the DOM glue.
